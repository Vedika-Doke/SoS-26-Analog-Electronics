# EE204 Homework — topic mapping

All from Prof. M. B. Patil's *Basic Electronics* course (IIT Bombay, 2018). Use these as practice alongside the weekly LTspice labs.

| File | Topics covered | Use in |
|------|----------------|--------|
| `mbp_2018_hw7.pdf` + `mbp_2018_key_hw7.pdf` | Op-amp with resistor tolerance, op-amp + RC saturation, **integrator design** (Q3–Q4), **offset voltage** effects (Q5), Wheatstone bridge common/differential mode (Q6–Q7), **3-op-amp instrumentation amplifier with CMRR** (Q8–Q13), difference amplifier CMRR (Q14–Q15) | Weeks 3 → 5 (most of it is gold for Week 5 inst-amp work) |
| `mbp_2018_hw8.pdf` | Bode plots & transfer functions (poles, zeros, magnitude plots) | **Skip** — we don't cover Bode formalism in this curriculum |
| `mbp_2018_key_hw9.pdf` (key only — no question file) | Answer key from EE204 HW9 | Reference only |
| `mbp_2018_hw12.pdf` | **DAC** resolution + weighted-resistor DAC + tolerance analysis (Q1, Q4, Q8–Q10), **ADC** topologies (flash, counter, SAR) (Q2, Q3, Q5–Q7, Q11), **555 monostable** internals with comparators + SR latch (Q12–Q13), **555 astable** internals (Q14) | Week 6 (Q1–Q11 for ADC/DAC); Week 7 (Q12–Q14 for the 555 project) |

## Quick picks per week

- **Week 3 (ideal op-amps):** HW7 Q3, Q4 (integrator design)
- **Week 4 (real op-amp limits):** HW7 Q5 (offset voltage)
- **Week 5 (inst-amp + filters):** HW7 Q6–Q15 (the core CMRR + inst-amp problems)
- **Week 6 (Schmitt + ADC/DAC):** HW12 Q1–Q11
- **Week 7 (555 project):** HW12 Q12–Q14 (literally drawn-out internals)
