Week 2

Diodes + BJT/MOS (light touch)

Exposure, not mastery. Recognize the devices in a schematic, know what they do, then move on.

Concepts: diode I-V + rectification + Zener; BJT regions (cutoff/active/sat) qualitatively; MOSFET as a voltage-controlled switch.

LTspice lab

  3. BJT as a switch — driving an LED.

Week 3

Op-amps I — Ideal linear circuits

The big one. Golden rules → almost every linear op-amp circuit becomes one-line algebra.

Concepts: virtual short; inverting / non-inverting / buffer; summer; difference; integrator; differentiator.

Slidesmc_opamp_1 → mc_opamp_3
ReadingFranco Ch. 1–2; S&S Ch. 2 cross-ref
HW2_instrumentation.pdf (easier problems)
LTspice labUse UniversalOpAmp2.
  1. Inverting amp, gain −10.
  2. Non-inverting amp, gain +5.
  3. Voltage follower under load.
  4. Summing amp — two DC inputs.
  5. Integrator — square in → triangle out. Large feedback R prevents DC drift.
Deliverable: Integrator producing a clean triangle from a square. Schematic + plot + hand calc.
Week 4 · Midterm window

Op-amps II — Real-world limits

Concepts: finite open-loop gain; GBW; input offset + bias current; output saturation. When each one bites.

Slidesmc_opamp_4, mc_opamp_5
ReadingFranco Ch. 5–6 (real op-amp limitations)
LTspice labTweak UniversalOpAmp2 parameters (Avol, GBW, Vos) without rewiring.

Week 5

Instrumentation amplifier + active filters

Linear op-amp applications before we flip into non-linear territory.

Concepts: difference amp recap; 3-op-amp instrumentation amp; CMRR; active filters; Sallen-Key topology (LP/HP/BP).

ReadingFranco — instrumentation-amp chapter + filter chapter
HW2_instrumentation.pdf — harder problems
LTspice lab

Week 6

Op-amps III — Non-linear: Schmitt, comparators, oscillators (+ ADC/DAC)

Flip from negative to positive feedback. Building blocks for the 555 timer and a lot of signal-conditioning.

Concepts: comparator (open-loop op-amp); Schmitt trigger + hysteresis; relaxation oscillator (Schmitt + RC); precision rectifier preview.

Slidesmc_opamp_6
ReadingFranco — comparators / non-linear chapter
LTspice lab
  1. Open-loop comparator — sine in, square out.
  2. Inverting Schmitt trigger — design for ±2 V thresholds; verify no chatter on noisy zero-crossings.
  3. Relaxation oscillator at 1 kHz — measure period, hand calc.
  4. Bonus: precision half-wave rectifier (works below 0.7 V).
Deliverable: Relaxation oscillator within 10 % of target frequency. Vcap and Vout on the same plot.

Bonus topic — ADC/DAC primer

Now that you've seen comparators and summing amps, you can understand every common ADC/DAC topology. Short survey:

  • DAC: weighted-resistor (a summing amp) → R-2R ladder (industry standard).
  • ADC: flash (parallel comparators, fastest) → counter / ramp → successive-approximation (SAR, most common) → sigma-delta (audio).
  • Resolution: full-scale range ÷ 2N.
  • Mini-lab: build a 4-bit weighted-resistor DAC, sweep all 16 codes, verify staircase.
  • HW: EE204 HW12 — Q1–Q11 here; Q12–Q14 (555 monostable + astable) in Week 7.
Week 7 · Project starts

Final project — design + first build

Pick one of the two projects. Both lean on weeks 3–6.

Option A — Analog differential-equation solver

Voltage at each node = a variable in the equation. Integrators integrate; summers + inverters wire up the equation. Solve a mass-spring-damper to get a damped sine on screen.

  • 2× integrators · 1× summer · 1× inverter · pre-charged caps for ICs.
  • References: Franco — analog computation section.

Option B — 555 timer from scratch (not the IC)

Rebuild the NE555 internals from discrete op-amps: two comparators, an SR latch, a discharge switch. Run as astable oscillator or monostable one-shot.

  • 2× comparators with 1/3 VCC and 2/3 VCC thresholds · SR latch · discharge transistor.
  • Reference: TI LM555 datasheet — functional block diagram.

Option C — Lotka-Volterra solver (stretch challenge)

Predator-prey ODEs: dx/dt = αx − βxy, dy/dt = δxy − γy. Same idea as Option A, but the xy terms are non-linear, so you need an analog multiplier (AD633). The reward: plot Vx vs Vy on an X-Y scope plot — the famous predator-prey limit cycle.

  • 2× integrators · 2× analog multipliers · summers + inverters · IC caps.
  • Reference: AD633 datasheet; Franco's analog computation chapter.
Week 7 deliverable: choice locked Day 1, block diagram on paper, first half built and simulating, hand calc of key parameters.
Week 8

Polish + report + presentation

  • Final report (4–6 pages): specs, schematic, hand calcs, sim results, failure-modes.
  • 15-min presentation: top-down walk-through + live LTspice demo + reflection.

Final-project options (recap)

  1. Analog differential-equation solver. Integrators + summers + inverters wired to solve an ODE. Mass-spring-damper → damped sinusoid as the canonical demo.
  2. 555 timer from scratch. Comparators + SR latch + discharge switch — same internals as the NE555. Astable or monostable mode.
  3. Lotka-Volterra solver (stretch). Predator-prey ODEs with non-linear xy coupling — needs an analog multiplier (AD633). Reward: a closed limit cycle on an X-Y plot.

LTspice things to teach explicitly

These trip everyone up — cover them deliberately rather than letting the mentee fight each one alone.

  • .tran 0 10m 0 1u — why max-step matters (default can alias HF content).
  • .dc V1 <start> <stop> <step> with nested .step param for family of curves.
  • .op for a quick DC operating-point check.
  • .measure directives — e.g. .meas TRAN tp TRIG V(out)=1 RISE=1 TARG V(out)=1 RISE=2 for period.
  • Importing manufacturer models: .include / .lib; adding symbols for parts not in the library.
  • UniversalOpAmp2 parameters: Avol, GBW, SR, Vos — study non-idealities without changing the schematic.
  • Probing current (Alt-click a component) vs voltage (click a wire).
  • Plotting power: Alt-click while holding shift — V·I.
  • Saving plot settings as .plt so the same view restores next time.
